# White-hat link building brief: a one-page template for an Indian service business

A scoped outreach month, not a bag of links. Agree this before any link building starts.

## 1. Name the pages
List 3 to 5 URLs to support: usually one service page, one location page and one proof page. Say which query each URL should own. Do not brief a blog post and a service page against the same commercial phrase.

## 2. Name the business and geography
A Chandigarh agency, a Mohali clinic and a multi-city retailer need different publications. Say who reads the linking page.

## 3. Name your inputs
A spokesperson, a customer question you can answer from experience, and any figure you can document. If a number cannot be documented, the piece will not use one.

## 4. Placements worth asking for
- A useful guest explanation on a niche site
- A resource-page mention of a guide you maintain
- A trade-publication angle with real data

## 5. Refuse
- Paid links sold as rankings, or packages priced by a DR number
- Private blog networks, article spinning, automated submission tools
- Site-wide footer or blogroll swaps
- Guest posts on unrelated topics
- Guaranteed positions or fixed ranking dates

## 6. Reporting
Each month: target URL, linking page, and the sentence around the link. "Links built" with no URL is not a report.
